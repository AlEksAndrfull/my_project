# Шаг 8 Декоратор log

Создаю модуль log_decorators, в котором будет описан декоратор log. Этот модуль будет использоваться для размещения различных декораторов, включая наш декоратор log.

Декоратор log должен автоматически фиксировать начало и завершение выполнения функции, а также её результаты или возникшие ошибки. Он должен принимать необязательный аргумент filename, который указывает, куда будут записываться логи (в файл или в консоль):
- Если filename задан, логи записываются в указанный файл.

- Если filename не указан, логи выводятся в консоль.

Логирование должно включать следующие элементы:
- Имя функции и результат выполнения, если операция завершилась успешно.

- Имя функции, тип возникшей ошибки и входные параметры в случае, если исполнение функции привело к ошибке.
