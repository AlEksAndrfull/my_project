# My Project

## Описание
Этот проект представляет собой виджет для обработки банковских операций клиента. Он позволяет фильтровать и сортировать транзакции по заданным критериям.

   ## Установка
   Для установки проекта клонируйте репозиторий:
  git clone https://github.com/AlEksAndrfull/my_project.git

### Шаг 6: Тестирование

## Структура тестов

- **Модуль "masks"**
- "get_mask_card_number": Тестирует правильность маскирования номера карты с различными входными формами.
- "get_mask_account": Проверяет работу функции маскирования номера счета.

- **Модуль "processing"**
- "filter_by_state": Тестирует фильтрацию списка словарей по заданному статусу.
- "sort_by_date": Проверяет сортировку списка словарей по датам в порядке возрастания и убывания.
### Запуск тестов

Для запуска всех тестов в проекте выполните следующую команду:
pytest
### Примеры тестов
Все тесты используют фикстуры для создания тестовых данных и параметризацию для проверки различных случаев.
